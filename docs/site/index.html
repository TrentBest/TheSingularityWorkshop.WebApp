01 / The boundary

One application role. Multiple hosts.

AnyApp describes the application-host role. WebApp is its web manifestation; the Windows/WPF host is a sibling manifestation, not a desktop service that the browser must proxy through.

WebApp owns

Browser capabilities

Web content, browser input, navigation, browser APIs, safe session boundaries, and web presentation.

Shared boundary

Application intent

Translate browser interactions into explicit requests. Preserve Experience identity and manifest meaning across hosts.

Not WebApp's job

Runtime ownership

Do not replace FSM_COS composition, FSM_API progression, or the canonical Experience lifecycle with a parallel browser loop.

03 / Honest status

A proving ground, not a finished runtime.

Current development state: the gateway → Moniker → hub vertical slice is transitional. The current implementation still owns a private heartbeat and multiple FSM contexts; the target is to replace that duplicate lifecycle with canonical AnyApp/FSM_COS behavior. This portal is a static architecture and documentation entry point, not the live WebApp runtime.
